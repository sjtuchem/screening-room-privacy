Privacy Policy for 并肩放映

并肩放映 synchronizes playback for two people watching supported Bilibili or YouTube videos in a shared room.

Information processed by the extension

The extension reads supported video page addresses, tab titles and player state to identify eligible video tabs and let you select one. Tab titles and the list of eligible tabs are processed locally. The extension saves the most recently used room server address, a random installation identifier for hosts, and the most recently accepted host invite in browser storage. It keeps room connection credentials and tab selection in browser session storage.

Information sent to the room server

When you create or join a room, the extension connects to the room server shown in its popup. The default server is screening-room-invite.onrender.com. You can enter a different WebSocket address, in which case the extension sends room data to the server you choose. The room service processes room codes, session tokens, the selected video's identifier, playback position, play or pause state, and playback speed. The service shares the selected video's identifier and playback state with the other participant. The default relay keeps active room state in memory, reserves a disconnected participant's seat for about two minutes, and temporarily uses the connecting IP address to limit connection rates.

When you create a room, the relay verifies your host invite and uses the installation identifier to distinguish your browser installation from another installation using the same invite. Guests use the room code. The supplied relay logs the invite number, the number of distinct installations involved, and the time when it detects a conflict. These entries omit the full invite, installation identifiers and IP addresses. The extension and relay do not collect payments or payment details.

The relay operator can retrieve an authenticated snapshot of invite numbers, current occupancy, recent conflict counts and revoked invite numbers. This snapshot omits full invites, room codes, installation identifiers and IP addresses.

The server or its hosting provider may handle network information under its own logging and retention settings. Remote connections use encrypted WebSockets. The extension does not send your Bilibili or YouTube passwords, cookies, or video stream to the room server.

Purpose and controls

The extension uses this information to connect participants, synchronize playback and recover from brief disconnects. The extension contains no advertising or analytics. You can leave the room through the extension and clear its saved settings by removing it. Each video platform handles its own sign-in and streaming under its own privacy policy.

Our use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

For privacy questions, use the publisher support contact on the Chrome Web Store or Microsoft Edge Add-ons listing for 并肩放映.
